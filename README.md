## 📌 Project Description

**FoodChow AI Chat Agent** is an AI-powered multilingual virtual assistant developed to provide intelligent, instant support to users of the FoodChow platform and POS (Point of Sale) software.

The chatbot uses Natural Language Processing (NLP), machine learning techniques, and Large Language Model (LLM) frameworks to understand user queries and deliver relevant software-related information.

It supports three languages:

- 🇬🇧 English
- 🇮🇳 Hindi
- 🇮🇳 Gujarati

The primary purpose of this project is to simplify restaurant software operations, improve customer experience, and reduce dependency on manual technical support.

## 🎯 Project Objectives

- Develop an intelligent AI-powered conversational assistant.
- Provide multilingual support for restaurant owners and staff.
- Understand and process software-related user queries.
- Deliver relevant answers through a structured knowledge base.
- Improve chatbot response accuracy and conversational experience.
- Provide instant guidance for FoodChow POS functionalities.
- Implement a fallback mechanism for unresolved queries.

## ✨ Key Features

### 1. Multilingual Conversational Support
- Supports English, Hindi, and Gujarati.
- Allows users to select their preferred communication language.
- Provides responses based on the selected language.
- Makes technical assistance accessible to a wider audience.

### 2. Natural Language Processing (NLP)
- Processes user questions using NLP techniques.
- Identifies keywords and understands user intent.
- Matches queries with structured training data.
- Handles different ways of expressing similar questions.

### 3. AI-Powered Response Generation
- Uses Google Gemini AI and Generative AI capabilities.
- Generates relevant responses based on user queries and context.
- Enhances conversational flow using alternative question and response phrasing.
- Provides interactive guidance and relevant information.

### 4. Knowledge-Based Query Handling
- Uses structured question-and-answer datasets.
- Organizes FoodChow POS-related information.
- Retrieves relevant answers for software usage, services, and pricing queries.

### 5. Human Support Escalation
- Provides a fallback mechanism for unresolved queries.
- Redirects users to human support when additional assistance is required.
- Helps maintain a continuous support experience.

### 6. Cross-Platform Integration
The AI assistant is integrated with:
- FoodChow official website.
- FoodChow POS software.
- FoodChow documentation platform.

## ⚙️ How It Works

The chatbot follows a structured conversation workflow:

**Step 1 – User Interaction**

The user initiates a conversation through the FoodChow platform.

**Step 2 – Language Selection**

The user selects English, Hindi, or Gujarati.

**Step 3 – Query Processing**

The chatbot receives the user's question and processes it using NLP techniques.

**Step 4 – Knowledge Retrieval**

The system identifies relevant information from its structured knowledge base and training dataset.

**Step 5 – Response Generation**

The AI assistant provides an appropriate response, guidance, quick links, or interactive options.

**Step 6 – Human Support Escalation**

If the chatbot cannot resolve the query, the user can be redirected to human support.

## 🧠 Dataset Preparation & Training

A structured dataset was prepared to improve chatbot understanding and response quality.

The preparation process included:

1. Collecting FoodChow POS-related information.
2. Identifying important software functionalities.
3. Preparing question-and-answer pairs.
4. Organizing the dataset using Google Docs and Google Sheets.
5. Formatting the data into CSV files.
6. Translating the dataset into Hindi and Gujarati.
7. Generating alternative question phrases to improve query handling.
8. Testing chatbot responses and refining the dataset.
